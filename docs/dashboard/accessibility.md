# Zugänglichkeit

Ziel WCAG 2.2 AA. Semantische Navigation, genau eine Seitenhauptüberschrift, Sprunglink, sichtbarer Tastaturfokus, beschriftete Eingaben, Tabellenüberschriften, verständliche Fehler und Text neben Statusfarben. Diagramme besitzen Tabellenalternativen; SVG ohne zusätzliche Information ist dekorativ. Systemschriften, 320-px-Layout, kein notwendiger Hover und prefers-reduced-motion. Automatisierte axe-Prüfungen ergänzen Tastatur-, Fokus- und Layoutprüfungen; sie ersetzen keine vollständige manuelle Prüfung mit allen Hilfsmitteln.
