# Meine Servergruppen

Die gemeinsame administrative Gruppenverwaltung wurde durch persönliche Gruppen ersetzt. Jeder Benutzer mit Serverzugriff kann seine eigenen Gruppen unter „Meine Servergruppen“ erstellen, umbenennen und löschen. Pro Konto sind bis zu 500 Gruppen möglich. Namen müssen nur innerhalb desselben Kontos eindeutig sein.

In der Serverübersicht oder den Serverdetails öffnet „Gruppen zuordnen“ eine Mehrfachauswahl eigener Gruppen. Das Speichern ersetzt nur die eigene Gruppenzuordnung dieses Servers. Die Gruppen anderer Benutzer und Zugriffsrechte bleiben erhalten. Ohne Auswahl ist der Server für das eigene Konto ungruppiert.

Die gruppierte Serverübersicht und der Gruppenfilter berücksichtigen nur die eigenen Gruppen. Mehrfach zugeordnete Server erscheinen unter mehreren Überschriften. Pagination zählt eindeutige Server; die Gruppierung bezieht sich auf die aktuelle Seite. Beim Löschen einer Gruppe werden keine Server gelöscht.

Details zu API, Migration und Isolation: [Persönliche Servergruppen](../../architecture/server-groups.md).
