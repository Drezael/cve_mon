# Manuelle Serverreihenfolge

Administratoren mit `server:reorder` können die globale Reihenfolge der Server ändern. Vollständige oder relative Verschiebungen verwenden die gespeicherte Versionsnummer und den bestehenden Bestätigungsprozess.

Die alte globale Gruppenreihenfolge und Reihenfolgen innerhalb gemeinsamer Gruppen wurden entfernt. Persönliche Servergruppen erscheinen alphabetisch; die Server verwenden die gewählte Sortierung. [Persönliche Gruppen](group-management.md).
