# Designsystem

Dunkle Navigation (#101d32), helle Inhaltsflächen, türkiser Akzent (#087582), Systemschriften und lokal gebündelte Lucide-SVGs. Karten, Tabellen, Badges und Faktenlisten verwenden gemeinsame Komponenten. Warnungen besitzen Text; Farbe ist nie die einzige Aussage. Kein CDN, kein externer Font, keine Inline-Styles. Mobile Navigation ab 700 px, einspaltige Karten bis 1100 px. Fokusrahmen, Sprunglink und reduzierte Bewegung sind berücksichtigt.
