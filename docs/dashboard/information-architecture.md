# Informationsarchitektur

Übersicht → Server/Gruppen → Findings → Benachrichtigungen. Jede Liste verwendet serverseitige Pagination. Details sind direkt adressierbar. Inventar, Matching, Priorität, Lebenszyklus und Risikoausnahme bleiben getrennte Aussagen. Berechtigte leere Bestände, fehlende Quellen, technische Fehler und verbotene Zugriffe sind verschiedene Zustände. Verwaltungsfunktionen gehören in Phase 21.
