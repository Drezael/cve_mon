# Administrator- und Benutzerhandbuch

Die vollständige aktuelle Anleitung liegt zentral unter
[**CVE Monitor – Bedienungsanleitung**](../bedienungsanleitung.md).

Sie beschreibt Installation, ersten Administrator, die aktuelle Dashboard-
Navigation, Server und Inventare, automatische lesende Ansible-Erfassung,
Findings, persönliche Dashboards, Mail und Berichte sowie Sicherung, Wartung
und Fehlerbehandlung.

Diese Seite bleibt als Einstieg für bestehende Dokumentverweise erhalten.
