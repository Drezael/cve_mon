# Server und Gruppen

„Meine Servergruppen“ verwaltet ausschließlich persönliche Gruppen. Die Serverübersicht bietet den Gruppenfilter und „Gruppen zuordnen“ je Server. Mehrfachzuordnungen sind möglich; der Server erscheint in jeder eigenen Gruppe. Nicht zugeordnete Server stehen unter „Ohne Gruppe“. Die Gruppierung bezieht sich auf die aktuelle Ergebnisseite, Pagination und Findings-Zahlen zählen weiterhin eindeutige Server.

Gruppen vergeben keine Rechte. Das Löschen einer Gruppe löscht keine Server. Die alte gemeinsame Gruppenverwaltung und Primärgruppenauswahl wurden ersetzt. [Bedienung](administration/group-management.md).
