# Historische Entwicklungsunterlagen

Die ursprünglichen Phasenaufträge unter `docs/history/plans/` sowie die alten
Umsetzungspläne `docs/development/phase-*-plan.md` sind ausschließlich lokal
archiviert. Sie werden durch `.gitignore` von Git und GitHub ausgeschlossen und
sind für Installation, Tests und Releases nicht erforderlich.

Für den aktuellen Betrieb gelten die [README](../../README.md), die
[Deployment-Dokumentation](../deployment/environments.md) und die aktuellen ADRs.
Die maschinenlesbare Liste der Release-Prüfpunkte liegt unabhängig von den
privaten Plänen unter
[acceptance-tasks.json](../../configuration/deployment/release/acceptance-tasks.json).

Historische Datei- und Hashlisten unter `docs/development/` beziehen sich auf den
jeweiligen damaligen Quellstand. Darin genannte lokale Pläne sind keine fehlenden
Bestandteile eines GitHub-Checkouts und keine aktuellen Betriebsanweisungen.
