# Queueverhalten Phase 23

Rückstände und Alter werden vom Statussampler minimiert erfasst. Leerlauf benötigt vorhandene Messung; unbekannte SMTP-Übergaben sind keine Erfolge. Bounded Retry und n8n-Regular-Mode bleiben erhalten. Ausfallprüfungen verwenden eigene Container/Namespaces und erzeugen keine echten Nachrichten.
