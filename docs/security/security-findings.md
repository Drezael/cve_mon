Die Befundliste trennt paketbezogene Scannerschwere und Plattformrisiko. Ein fehlender Fix beziehungsweise ein deaktivierter optionaler n8n-Knoten ist keine automatische Genehmigung. Für offene Befunde sind Update, nachgewiesene Nichtbetroffenheit oder ausdrücklich genehmigte kompensierende Maßnahmen erforderlich. Der ausführbare Gate kennt keine pauschale Ignoreliste.

Finaler Stand: null blockierende Fundstellen in 13 Images und fünf Dependencygraphen. Die 694 ursprünglichen Fundstellen bleiben archiviert. Zusätzlich prüfen native Komponentenproben die tatsächlich geladenen Bibliotheken. [Behebung](phase-23-remediation.md), [Befundregister](phase-23-image-findings.md). Keine genehmigten Ausnahmen.
