# OSV-Evidenz

Advisory-ID, Aliase, related/upstream, Withdrawn, affected.package, Ökosystem, Name, Original-PURL,
Versionslisten und Ranges einschließlich introduced/fixed/last_affected/limit und Git-Kontext
bleiben erhalten. Nichts wird durch einen universellen Versionsvergleich vereinheitlicht.
Eine PURL oder CPE wird nicht erfunden; gleiche Paketnamen verschiedener Ökosysteme sind
keine gemeinsame Paketidentität.

Mehrere CVE-Aliase erzeugen getrennte Kanten und einen expliziten Mehrdeutigkeitskonflikt.
Betroffenheitsevidenz solcher Advisories ist nicht ohne spätere Identitätsprüfung verwendbar.
Withdrawn bleibt historisch und seine Evidenz wird nicht als uneingeschränkt aktiv ausgegeben.
Eine Advisory ohne CVE bleibt eigenständig. Entfernte Aliase führen zur Neuverarbeitung auch
der bisher zugeordneten CVEs. NVD-AND/OR/Negate-Konfigurationen werden ebenfalls als vollständige
Logikbäume erhalten; keine Reduktion auf eine flache Liste vermeintlich betroffener CPEs.
