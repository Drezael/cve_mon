# Prüfungen

make check prüft Entwicklungswerkzeuge und die Phase-0-Verträge. make validate validiert
OpenAPI, lokale Referenzen, Inventarschema und positive/negative Beispielerwartungen.
[Architektur-Abnahmeszenarien](architecture-acceptance-scenarios.md) beschreiben spätere
Runtime-Tests; diese sind noch nicht als ausgeführt zu bewerten.
