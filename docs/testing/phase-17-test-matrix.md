# Phase-17-Testmatrix

Die 176 verpflichtenden Prüfpunkte aus dev_docs/phase_17.md sind folgenden konkreten
Implementierungs- und Testnachweisen zugeordnet. Fachliche Unsicherheit wird als Ergebnis
geprüft; fehlende OVAL-/SBOM-/Commitgraph-/CPE-Voraussetzungen sind keine behauptete Erkennung.
Die fünf Statuswerte sind durch Komponenten, Aggregation und Lebenszyklusregeln getrennt.
`not_affected` ist für auswertbare Komponenten verfügbar; globale Serverentwarnung setzt
eine derzeit nicht belegte exhaustive Abdeckung voraus und wird nicht vorgetäuscht.
