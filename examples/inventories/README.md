# Synthetische Beispielinventare

Diese Dateien zeigen die unterstützten Inventarformate für den Dashboard-Upload.
Hostnamen, IDs und Daten sind Demonstrationswerte.

| Datei | Inhalt |
|---|---|
| [clean-server.json](clean-server.json) | Kleines Hostinventar ohne zusätzliche Pakete |
| [vulnerable-server.json](vulnerable-server.json) | Hostinventar mit einem Beispielpaket |
| [vulnerable-containers.json](vulnerable-containers.json) | Inventar mit Container-Softwaredaten |

Erfassungszeitpunkte und Inventar-IDs sind feststehende Beispielwerte. Für aktuelle
eigene Daten die [Ansible-Erfassung](../../integrations/ansible/README.md) verwenden.
