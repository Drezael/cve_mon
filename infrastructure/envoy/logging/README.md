# Envoy-Teilbereich

Dieser Teilbereich wird vollständig in die einzelne unterstützte v3-Gesamtkonfiguration
integriert. Maßgeblich sind die Policy und scripts/infrastructure/envoy.py; es existieren
keine parallelen, nur scheinbar automatisch eingebundenen YAML-Fragmente.
Betrieb, Rechte, Logs, Health und SMTP-Vertrag sind unter docs/deployment/envoy.md beschrieben.
