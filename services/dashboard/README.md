# cve-dashboard

UI erst in Phase 20–21. Gemeinsame technische Konfiguration, Logs und HTTPX können
später aus dem installierten cve_common verwendet werden; kein direkter DB-Zugang,
keine eigene Autorisierung anhand frei wählbarer Header und kein neuer Container
in Phase 6. Der vorhandene Bereich administration bleibt als fachliche Abgrenzung erhalten.
