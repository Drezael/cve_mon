# cve-inventory 0.14.0

Registrierter PostgreSQL-Worker für persistierte Inventar-Submissions 1.0 und 1.1.
Ressourcenbegrenzte Revalidierung und verlustfreie Normalisierung; unveränderliche
Snapshots, Historie, Current-Pointer, Audit/Outbox und interne Health/Metriken.
Verwendet cve-common 0.7.0 und Rolle inventory_processor, ausschließlich cve_data.
